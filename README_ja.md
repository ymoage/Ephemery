# Ephemery

[English](README.md) | [日本語](#ephemery)

スクリーンショットやクリップボード画像を一時ファイルに保存し、ホットキーでファイルパスを貼り付けできる Windows トレイアプリケーション。

**Ephemery** (ephemeral + memory) - 一時的なスクリーンショット保存で、素早くファイルパスにアクセス。

> 💡 **AI ワークフローに最適！** AI アシスタント（Claude、ChatGPT など）にスクリーンショットを共有する際、画像を手動でアップロードする代わりにファイルパスを貼り付けるだけ。

## なぜ Ephemery？

AI アシスタントにスクリーンショットを共有したいとき、画像のコピー＆ペーストが面倒だと感じたことはありませんか？Ephemery がそれを解決します：

1. **キャプチャ** - `Ctrl+Alt+S` でスクリーンショットを撮影
2. **パス貼り付け** - `Ctrl+Alt+P` を押してファイルパスを入力
3. **AI 対応** - AI アシスタント（Claude Code、ChatGPT など）が画像を読み取れます

もう不要：
- ❌ 手動でのファイル保存とナビゲーション
- ❌ ドラッグ＆ドロップの面倒な操作
- ❌ 画像を1つずつアップロード

キャプチャして、パスを貼り付けるだけ。完了。

## 機能

- 📸 **画面キャプチャ** - Snipping Tool 風の範囲/ウィンドウ選択
- 📋 **クリップボード保存** - クリップボードから画像をキャプチャ
- ⌨️ **パス貼り付け** - ホットキーでファイルパスを貼り付け（SendInput）
- ⚙️ **カスタマイズ可能** - ホットキーとファイル保持上限を設定
- 🔄 **FIFO 管理** - 古いファイルを自動削除（デフォルト: 10 ファイル）
- 🪶 **軽量** - わずか 181KB（Release ビルド）

## 使い方

### デフォルトホットキー

| ホットキー | 動作 |
|-----------|------|
| `Ctrl+Alt+S` | 画面キャプチャ（範囲/ウィンドウ選択） |
| `Ctrl+Alt+C` | クリップボード画像を保存 |
| `Ctrl+Alt+P` | ファイルパスを貼り付け |

### 動作の仕組み

1. **キャプチャ**: `Ctrl+Alt+S` で画面をキャプチャ、または `Ctrl+Alt+C` でクリップボード画像を保存
2. **自動保存**: 画像は `%TEMP%\Ephemery\` に PNG ファイルとして保存されます
3. **貼り付け**: `Ctrl+Alt+P` を押すと全ファイルパスが入力されます（改行区切り）
4. **自動クリーンアップ**: 保持上限に達すると古いファイルから削除されます（FIFO）

### 画像の保存方法

Ephemery はシステムの一時フォルダに画像を保存します：

**保存場所**: `%TEMP%\Ephemery\`

**ファイル名**: `ephemery_YYYYMMDD_HHMMSS_N.png`
- 日時スタンプで識別しやすい
- 連番で競合を防止

**ライフサイクル**:
1. キャプチャ直後に画像が保存される
2. ファイルパスがメモリで追跡される
3. 保持上限（デフォルト: 10）に達すると、古いファイルから削除される（FIFO）
4. アプリ再起動時、フォルダ内の既存画像は保持されるが、パスリストには読み込まれない
5. 画像はディスク上に残り、上書きまたは手動削除されるまで存在する

**なぜ一時保存？**
- 高速アクセス（ネットワーク/クラウド依存なし）
- Windows による自動クリーンアップ（最終的に）
- クラウドストレージの容量/プライバシーの懸念なし

### 設定

トレイアイコンを右クリック → **設定** で：
- ホットキーを変更
- ファイル保持上限を調整（1-100）

## ソースからビルド

### 前提条件

- Visual Studio 2022
- CMake 3.20+
- Windows 10/11 SDK

### ビルド手順

```bash
# リポジトリをクローン
git clone https://github.com/ymoage/Ephemery.git
cd Ephemery

# CMake でビルド
mkdir build
cd build
cmake .. -G "Visual Studio 17 2022" -A x64
cmake --build . --config Release

# 出力: build/Release/Ephemery.exe
```

または Visual Studio 2022 で CMake プロジェクトとしてフォルダを開く。

## 技術詳細

- **言語**: C++17
- **UI フレームワーク**: Pure Win32 API
- **グラフィック**: GDI+（PNG エンコード）、BitBlt（画面キャプチャ）
- **ホットキー**: RegisterHotKey API
- **入力**: SendInput API
- **設定**: JSON（%APPDATA%\Ephemery\settings.json）
